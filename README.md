### ✨ Qué tiene

- **Bilingüe (ES/EN)** — con detección automática y URLs dedicadas.
- **Tema claro/oscuro** — respeta la preferencia del sistema, con toggle manual.
- Secciones: Sobre mí · Habilidades · Experiencia · Proyectos · Certificaciones · Contacto
- Formulario de contacto funcional. (Formspree)
- 100% responsive, sin dependencias pesadas.
- Recomendaciones reales de referencias laborales.

---

### 🛠️ Stack

Construido a mano, sin frameworks — HTML semántico, CSS con custom properties y JavaScript vanilla (Intersection Observer para animaciones, sin librerías externas de UI).

```
├── index.html      → Estructura y contenido
├── style.css       → Estilos, temas y responsive
├── script.js       → Interactividad, idiomas y formulario
└── vercel.json     → Configuración de despliegue
```
